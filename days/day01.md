# 第1天：阶段一 / 电化学基础 — 全钒液流电池是什么

**5分钟复习**

储能技术多样，全钒液流电池（VRB）是目前大规模长时储能的主流技术路线之一。今天我们从电化学基础出发，理解VRB的储能原理与核心优势。

---

**10分钟学习**

### 1. 电池与电化学基础

- 电池本质是**氧化还原反应**的能量转换装置：
  - 放电：化学能 → 电能
  - 充电：电能 → 化学能
- 两个电极通过**电解质**（含有导电离子的溶液）连接；外电路连通后，电子从负极流向正极，离子在电解质中迁移，形成完整电流回路
- **关键概念**：氧化（失电子）和还原（得电子）必然同时发生，电子守恒、电荷守恒

### 2. 液流电池的核心结构

- 液流电池与普通电池最大的区别在于：**储能介质不在电极内部，而是溶解在电解液中**
- VRB的电解液含有钒离子（V²⁺/V³⁺在负极，VO²⁺/VO₂⁺在正极），储存在外部储罐中
- 充电时：V³⁺ → V²⁺（负极），VO²⁺ → VO₂⁺（正极）；放电时反向
- 充放电过程本质是**钒离子价态的可逆变化**，能量存储在电解液的化学态中

### 3. VRB储能系统五大核心组件

| 组件 | 作用 |
|------|------|
| **电堆（Stack）** | 多节单电池串联，是电化学反应核心场所，决定最大功率 |
| **电解液储罐** | 储存含钒离子的酸性溶液，是真正的"储能介质"，决定容量 |
| **离子交换膜** | 隔离正负极电解液，只允许H⁺通过，防止短路 |
| **泵与管路** | 驱动电解液在电堆与储罐之间循环流动 |
| **功率单元与控制系统** | 电力电子变换与BMS管理充放电过程 |

### 4. VRB与其他储能技术的根本差异

- **锂电池**：储能"固定"在电极材料中，容量受限 → 能量型储能受限
- **液流电池**：储能"溶解"在电解液里，电堆功率与电解液容量**独立设计** → 功率（kW）与容量（kWh）解耦
- 这意味着：VRB可以通过**增大电解液储罐**来低成本扩展储能时长（4h、8h甚至12h+），而锂电池延长时长成本陡增
- 中国已有多个百MWh级项目（大连100MW/400MWh等），VRB是长时储能的重要技术路线之一

**5分钟复盘**

- **本节核心**：VRB的本质是钒离子价态变化的氧化还原电池，其独特之处在于储能介质存储在外部储罐中，实现功率与能量的独立设计，这是大规模长时储能的关键优势。
- **思考题**：如果将VRB的电解液体积增大一倍，但电堆规格不变，电池的哪个参数会显著增加，哪个参数基本不变？

> 答案提示（明日揭晓）：功率（kW）基本不变，储能容量（kWh）会增加。
